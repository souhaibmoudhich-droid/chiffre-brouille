Chiffre Brouillé

Un nombre, quelques lettres qui ne veulent rien dire, puis ton message décalé dans l'alphabet.

Difficulté

La personne qui reçoit le message doit connaître ce mot, écrit exactement pareil. Sans lui, le message est illisible.

Ce décalage est celui du premier nombre. Chaque nouveau nombre dans le message le change.

Comment ça marche
  1. Le message commence par un nombre de 1 à 9.
  2. Les lettres qui suivent, autant que le nombre, ne veulent rien dire. On les jette.
  3. Ensuite vient le vrai message : chaque lettre est avancée d'autant de places que le nombre. Après Z, on repart à A.
  4. Si un autre nombre apparaît plus loin, on recommence : on jette autant de lettres, puis le décalage devient ce nouveau nombre.
  5. Les chiffres de ton message sont écrits en lettres (8 devient HUIT), pour ne pas les confondre avec les nombres du code.
  6. Exemple : 2LRUCN4ABCDYX donne SALUT.
  7. Niveau Secret : le message est verrouillé avec un mot secret, puis écrit avec un mélange de lettres latines, de lettres arabes, de chiffres et de signes. Il commence toujours par #. Sans le mot secret, on ne peut pas le lire.
